# Игровой Discord-бот: структура сервера, Join-to-Create и новости

Стек: Python 3.10+, disnake, aiohttp, aiosqlite, feedparser.

## Структура проекта

```
game-bot/
├── bot.py              # точка входа, Intents, загрузка Cogs
├── config.py           # настройки из .env
├── database.py         # работа с SQLite (aiosqlite)
├── cogs/
│   ├── setup.py        # /setup-server: роли, категории, каналы, панели
│   ├── voice.py        # Join-to-Create: временные голосовые комнаты
│   ├── news.py         # опрос RSS, защита от дублей, Embed
│   └── control.py      # панель #control-panel (кнопки, модальные окна, Select)
├── requirements.txt
└── .env.example
```

## 1. Создание приложения в Discord

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) и создайте приложение.
2. Во вкладке **Bot** скопируйте токен (он понадобится для `DISCORD_TOKEN`).
3. Привилегированные Intents (`Server Members`, `Message Content`) **включать не нужно**: бот использует только обычные Intents `Guilds` и `Voice States`, которые задаются в коде (`bot.py`).
4. Пригласите бота через **OAuth2 → URL Generator**: отметьте scope `bot` и `applications.commands`, а в правах выберите **Administrator** (нужно для создания ролей и каналов). Если хотите минимальные права, понадобятся: Manage Roles, Manage Channels, Manage Messages, Move Members, View Channels, Send Messages, Embed Links, Read Message History, Connect, Speak.

## 2. Установка

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
```

Заполните `.env`:

- `DISCORD_TOKEN` — токен бота (обязательно);
- `GUILD_ID` — ID вашего сервера (для мгновенной синхронизации slash-команд; включите режим разработчика в Discord, затем ПКМ по серверу → «Копировать ID»);
- `NEWS_CHECK_INTERVAL` — интервал опроса лент в секундах (по умолчанию 900).

## 3. Запуск

```bash
python bot.py
```

Затем на сервере выполните команду **`/setup-server`** (нужна роль администратора). Она:

- создаст роли `Administrator`, `Moderator`, `Member`, а также роли платформ (PC, PlayStation, Xbox, Nintendo Switch, Mobile) и жанров (RPG, FPS, Стратегии, Инди, MOBA);
- создаст категории и каналы: «Информация», «Игровые новости», «Общение», «Голосовые каналы», «Временные комнаты» и скрытую «Администрация» (`#log-bot`, `#control-panel`);
- сохранит ID хаба и категории в базе данных;
- опубликует панель выбора ролей в `#выбор-ролей` и панель управления в `#control-panel`.

Команда идемпотентна: при повторном запуске объекты не дублируются.

Выданные роли `Administrator` и `Moderator` назначаются вручную через стандартные настройки Discord.

## 4. Как пользоваться

**Join-to-Create.** Пользователь заходит в «➕ Создать комнату», бот создаёт канал «🔊 Комната | Имя» в категории «Временные комнаты» и переносит туда пользователя. Владелец может выполнять команды:

- `/room limit value:4` — лимит участников (0 — без ограничений);
- `/room lock locked:True` — закрыть комнату для остальных (или `False`, чтобы открыть).

Когда комната пустеет, бот удаляет её через 5 секунд, если никто не вернулся.

**Новости.** В `#control-panel` доступны кнопки:

- ➕ Добавить источник — название и RSS/Atom-ссылка, затем выбор канала;
- 🗑️ Удалить источник;
- 🔗 Привязать к каналу;
- 🔄 Проверить сейчас — принудительный опрос;
- 📋 Список источников.

Чтобы добавить игру, найдите RSS-ленту (у Reddit это `https://www.reddit.com/r/<сабреддит>/.rss`, у многих сайтов есть `/feed` или `/rss`) и добавьте её через панель.

## 5. Замечания

- При первом опросе новой ленты бот запоминает текущие записи без публикации, поэтому канал не заспамит старыми новостями.
- Выпадающие списки Discord ограничены 25 вариантами. Если на сервере больше текстовых каналов, в списке отобразятся первые 25.
- Для работы через Reddit бот использует осмысленный User-Agent; при блокировке со стороны сайта смените источник или увеличьте интервал опроса.
- База данных `bot.db` создаётся автоматически. Для резервного копирования достаточно скопировать этот файл.
